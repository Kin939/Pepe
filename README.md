# Pepe Auto Sell

Клиентский мод для **Minecraft 26.3, NeoForge 26.3.0.95, Java 25**.
Готовые сборки: [Releases](https://github.com/Kin939/Pepe/releases).

## Использование

1. Установите NeoForge 26.3.0.95 и положите JAR из Releases в `mods` клиента.
2. Нажмите **C**, затем ПКМ по жителю. Клавиша переназначается в управлении.
3. Мод использует доступные сделки с результатом в изумрудах до исчерпания
   материалов, запаса жителя или свободного места. Окно торговли не отображается.
4. Повторное **C** выключает режим, закрывает скрытый контейнер и убирает эффекты.

Работает через стандартные клиентские пакеты обмена; серверный мод не нужен.
Не обходит лимиты, расстояние взаимодействия, цены или правила сервера.
Используется ванильный массовый обмен (Shift-click результата). Мод автоматически
дозаполняет входные слоты и продолжает продавать одному жителю до лимита.
Ожидание только синхронизации сервера; искусственных пауз между сделками нет.
На серверах с ограничениями автоматизации используйте только с разрешения администрации.

## Фильтр

`Mods → Pepe Auto Sell → Config` либо `config/pepe-client.toml`:

```toml
allowlist = false
items = ["minecraft:diamond", "minecraft:netherite_ingot"]
protectSpecialItems = true
```

`allowlist=false` — исключить перечисленные предметы; `true` — продавать только их.
По умолчанию список пуст (разрешены все обычные предметы), защищены именованные,
зачарованные, повреждённые предметы и предметы с содержимым.
Для безопасности, если в инвентаре есть защищённый предмет того же типа, весь
соответствующий обмен пропускается: ванильное автозаполнение само выбирает стек.
Обмены, требующие изумруды на входе, не выполняются.

## Эффекты

Уведомления о полученных изумрудах справа сверху; качающийся текст возле прицела.
Один завершённый заход к жителю, в котором удалось что-либо продать, = один шаг
комбо независимо от числа сделок, предметов и изумрудов. Пустое взаимодействие и
повторный клик по исчерпанному жителю комбо не дают. После восьмого — сброс
счётчика, радужный текст и дождь из 500 экранных изумрудов, падающих втрое быстрее.
Комбо сохраняется между жителями до восьми или выключения режима.

Справа снизу — общий заработок изумрудов за включение режима, с подпрыгиванием
при поступлении прибыли. На каждом пороге 64, 128, 192… по экрану пролетает
вращающийся 2D-спрайт жителя со звуком `musor_drop`. За несколько стаков сразу —
несколько пролётов очередью. Это только GUI-текстуры: сущности не создаются даже для отрисовки.
Счётчик и очереди сбрасываются как при включении, так и при выключении режима.

Если ничего не продано, звучит ошибка; если продана часть, а остальное недоступно,
лишняя ошибка не звучит.

Все 13 записей из репозитория включены: музыка, касса, ошибка, выключение и комбо 1–8.
Музыка зациклена, при выключении режима останавливается. Подробнее: [AUDIO.md](AUDIO.md).

## Сборка

```sh
./gradlew build
```

Нужны JDK 25 и доступ к Maven NeoForge и Mojang. JAR: `build/libs/pepe-1.0.8.jar`.
GitHub Actions собирает и публикует JAR только после успешной компиляции.

## Проверка перед использованием на ценном инвентаре

Сборка не заменяет испытания в игре. Проверьте в тестовом мире:
- 60 тыкв при цене 6 → 10 изумрудов (если запас сделки позволяет);
- исчерпанный обмен и отсутствие материалов → ошибка без продажи;
- полный инвентарь → безопасная остановка;
- фильтр, защищённые предметы и сделки с двумя входными предметами;
- C во время обмена, выход из мира, потеря связи, повторный ПКМ;
- 8 успешных заходов к жителям → дождь, следующий успешный заход → Combo 1;
- 63 + 1 заработанных изумруда → один пролёт; 128 сразу → два;
- выключение/включение режима → заработок 0, эффекты сброшены;
- обычная торговля при выключенном режиме.

Если входные слоты не заполнились за три секунды, сделка пропускается.
Одна сессия ограничена минутой, после чего можно снова нажать ПКМ.

## Подсветка торговли (1.0.8)

Только в режиме C: зелёный glow — есть хотя бы одна доступная сделка с изумрудами
на выходе и в инвентаре хватает разрешённых фильтром предметов для полной оплаты.
Красный — сделки исчерпаны или нужных предметов нет/недостаточно. Учитываются обе
цены, компоненты предметов и защита особых вещей, как при автопродаже. Цвет
пересчитывается каждый тик по сохранённым сделкам и текущему инвентарю; повторная
проверка сервера для изменений инвентаря не нужна. Неизвестный статус и отсутствие продаж
за изумруды не подсвечиваются. Серверные команды и команды scoreboard не меняются.

Автопроверка открывает скрытую торговлю только для чтения: не продаёт, не двигает
предметы и не начисляет комбо. Нужны пустая вторая рука, видимость и расстояние
не более 2.5 блока (и не больше текущей дистанции взаимодействия). Общий лимит —
одна проверка в 1.5 секунды. Исчерпанные сделки перепроверяются не чаще раза в
10 секунд, остальные — раз в 30 секунд. При группе жителей проверка идёт очередью.
Вне дистанции запас сделок остаётся последним известным; наличие предметов
по-прежнему пересчитывается локально. Пополнение запаса требует успешной проверки.
Подсветка проверяет оплату, но не гарантирует свободное место под результат. На серверах автоматизация
может быть запрещена: используйте только с разрешения администрации.

Обычный ПКМ имеет приоритет и при необходимости ждёт окончания текущей проверки.
При выключении режима подсветка и очередь проверок отключаются, кэш очищается.

## Эффекты режима продажи (1.0.8)

Изумрудная виньетка, мягкое «дыхание» FOV ±1.25% за 5 секунд и еле заметные
односекундные вспышки: зелёная после заработка, красная при неудачном обмене или
визите без продаж. Вспышки не накапливают непрозрачность. Фоновые проверки их не
запускают. Надпись `AUTO SELL [C]` убрана, клавиша по-прежнему переназначается через
«Настройки → Управление → Назначение клавиш → Pepe Auto Sell» (категория «Разное»).

Оригинальная CRT-панель PEPE TV слева внизу показывает пять 2D-эмоций жителя:
нейтральная, успех, неудача, каждые 64 заработанных изумруда и максимальное комбо.
Максимальное комбо и достижение стака имеют приоритет над обычными эмоциями.
Панель размещена выше нижней полосы хотбара. Отключение C или выход из мира
очищают эффекты. FOV игрока не сохраняется/не перезаписывается, в меню не пульсирует.
