# Pepe Auto Sell

Клиентский мод для **Minecraft 26.3, NeoForge 26.3.0.95, Java 25**.
Готовые сборки: [Releases](https://github.com/Kin939/Pepe/releases).

## Использование

1. Установите NeoForge 26.3.0.95 и положите JAR из Releases в `mods` клиента.
2. Нажмите **C**, затем ПКМ по жителю. Клавиша переназначается в управлении.
3. Мод использует доступные сделки с результатом в изумрудах до исчерпания
   материалов, запаса жителя или свободного места. Окно торговли не отображается.
4. Повторное **C** выключает режим, закрывает скрытый контейнер и убирает эффекты.

Работает через стандартные клиентские пакеты обмена; серверный мод не нужен.
Не обходит лимиты, расстояние взаимодействия, цены или правила сервера.
Одна сделка подтверждается отдельно: это не мгновенная продажа за один пакет.
На серверах с ограничениями автоматизации используйте только с разрешения администрации.

## Фильтр

`Mods → Pepe Auto Sell → Config` либо `config/pepe-client.toml`:

```toml
allowlist = false
items = ["minecraft:diamond", "minecraft:netherite_ingot"]
protectSpecialItems = true
```

`allowlist=false` — исключить перечисленные предметы; `true` — продавать только их.
По умолчанию список пуст (разрешены все обычные предметы), защищены именованные,
зачарованные, повреждённые предметы и предметы с содержимым.
Для безопасности, если в инвентаре есть защищённый предмет того же типа, весь
соответствующий обмен пропускается: ванильное автозаполнение само выбирает стек.
Обмены, требующие изумруды на входе, не выполняются.

## Эффекты

Уведомления о полученных изумрудах справа сверху; качающийся текст возле прицела.
Одна завершённая сделка = один шаг комбо. После восьмой — сброс счётчика,
радужный текст и дождь из 500 экранных изумрудов (не предметы в мире).
Комбо сохраняется между жителями до восьми или выключения режима.
Если ничего не продано, звучит ошибка; если продана часть, а остальное недоступно,
лишняя ошибка не звучит.

**Аудиозаписи из запроса отсутствовали в репозитории.** Включены временные оригинальные
эффекты; точная музыка и soundboard требуют добавления файлов. Инструкция: [AUDIO.md](AUDIO.md).

## Сборка

```sh
./gradlew build
```

Нужны JDK 25 и доступ к Maven NeoForge и Mojang. JAR: `build/libs/pepe-1.0.0.jar`.
GitHub Actions собирает и публикует JAR только после успешной компиляции.

## Проверка перед использованием на ценном инвентаре

Сборка не заменяет испытания в игре. Проверьте в тестовом мире:
- 60 тыкв при цене 6 → 10 изумрудов (если запас сделки позволяет);
- исчерпанный обмен и отсутствие материалов → ошибка без продажи;
- полный инвентарь → безопасная остановка;
- фильтр, защищённые предметы и сделки с двумя входными предметами;
- C во время обмена, выход из мира, потеря связи, повторный ПКМ;
- 8 сделок → дождь, следующая сделка → Combo 1;
- обычная торговля при выключенном режиме.

При задержке подтверждения больше трёх секунд мод безопасно прекращает обмен.
Одна сессия ограничена минутой, после чего можно снова нажать ПКМ.
