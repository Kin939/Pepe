## 1.0.6 — цветной glow и автопроверка сделок

Зелёная обводка — доступна продажа за изумруды; красная — все такие сделки исчерпаны.
Подсветка только в режиме автопродажи. Непроверенные жители и жители без подходящих
сделок не подсвечиваются. Цвет не зависит от наличия предметов в инвентаре игрока.

Автопроверка только для чтения, без продаж/звуков/комбо: видимые взрослые жители
в пределах 2.5 блока и обычной дистанции взаимодействия, при пустой второй руке.
Не больше одного запроса в 1.5 секунды; красные перепроверяются не чаще раза в
10 секунд, остальные — раз в 30 секунд. Пополнение подтверждается ответом сервера,
а не таймером. Вдали от игрока статус остаётся последним известным.

Серверные команды, команды scoreboard и флаг glowing сущности не изменяются.
Используется штатный модификатор render state NeoForge для существующих жителей,
без создания дополнительных сущностей и без возврата проблемного 3D-пролёта.
Нужна разрешённая на сервере автоматизация. Подробности и ограничения — README.
Удалите старый JAR перед установкой pepe-1.0.6.jar.

Клиентский мод для Minecraft 26.3 / NeoForge 26.3.0.95, Java 25.

Установка: положить pepe-1.0.6.jar в папку mods **клиента**. На сервер устанавливать не нужно.

C — включение/выключение (можно переназначить). ПКМ по жителю — продажа за изумруды без отображения окна. Серверные лимиты сохраняются. Фильтр доступен через Mods → Pepe Auto Sell → Config и config/pepe-client.toml.

Комбо 1–8, сброс после 8, радужный финал и 500 экранных изумрудов. При отключении эффекты и музыка останавливаются.

Включены все запрошенные аудиозаписи из репозитория: Villager Sings MONTAGEM XONADA (зациклена), касса, ошибка, perfect-fart и восемь звуков комбо.

Сборка проверена компилятором в GitHub Actions. Интерактивная проверка в игровом клиенте и на серверах не проводилась.
