## 1.0.3 — комбо за жителя, заработок и пролёты

- Один полностью обработанный заход к жителю с успешной продажей = один шаг комбо. Число сделок внутри захода больше не увеличивает комбо. Пустые клики и исчерпанные жители не считаются; прерванный заход не награждается комбо.
- Изумруды финального дождя падают втрое быстрее.
- Справа снизу — общий заработок за текущий режим продажи. Сброс при включении/выключении и выходе из мира.
- За каждые 64 заработанных изумруда — отдельный пролёт вращающейся GUI-модели жителя со звуком musor_drop из репозитория. Несколько порогов за один обмен не теряются.
- Массовая продажа и фильтр сохранены.

Удалите старый JAR перед установкой pepe-1.0.3.jar. Настройки фильтра сохраняются.
Сборка и автоматические тесты выполняются в CI; интерактивная проверка в игровом клиенте не проводилась.

Клиентский мод для Minecraft 26.3 / NeoForge 26.3.0.95, Java 25.

Установка: положить pepe-1.0.3.jar в папку mods **клиента**. На сервер устанавливать не нужно.

C — включение/выключение (можно переназначить). ПКМ по жителю — продажа за изумруды без отображения окна. Серверные лимиты сохраняются. Фильтр доступен через Mods → Pepe Auto Sell → Config и config/pepe-client.toml.

Комбо 1–8, сброс после 8, радужный финал и 500 экранных изумрудов. При отключении эффекты и музыка останавливаются.

Включены все запрошенные аудиозаписи из репозитория: Villager Sings MONTAGEM XONADA (зациклена), касса, ошибка, perfect-fart и восемь звуков комбо.

Сборка проверена компилятором в GitHub Actions. Интерактивная проверка в игровом клиенте и на серверах не проводилась.
