## 1.0.5 — пролёт жителя без создания сущности

Полностью удалён путь отрисовки 3D-жителя: больше нет создания Villager,
GUI-фабрики сущностей, ID сущности и вызова InventoryScreen/рендерера мобов.
За каждый заработанный стак теперь пролетает оригинальный прозрачный 2D-спрайт
жителя, вращаясь два полных оборота. Пролёт и musor_drop сохранены.
Комбо за успешный заход к жителю, заработок, массовая торговля и ускоренный дождь
не изменены. Удалена ненужная тестовая зависимость Mockito.

Это устранение известного проблемного пути рендера. Причина последнего нативного
падения jvm.dll без hs_err не установлена, поэтому полное устранение того падения
не подтверждено. Проверка запуска с пользовательской сборкой не проводилась.
Добавлены проверки ресурса, движения и отсутствия зависимостей рендера от сущностей.

Удалите старый JAR перед установкой pepe-1.0.5.jar.

Клиентский мод для Minecraft 26.3 / NeoForge 26.3.0.95, Java 25.

Установка: положить pepe-1.0.5.jar в папку mods **клиента**. На сервер устанавливать не нужно.

C — включение/выключение (можно переназначить). ПКМ по жителю — продажа за изумруды без отображения окна. Серверные лимиты сохраняются. Фильтр доступен через Mods → Pepe Auto Sell → Config и config/pepe-client.toml.

Комбо 1–8, сброс после 8, радужный финал и 500 экранных изумрудов. При отключении эффекты и музыка останавливаются.

Включены все запрошенные аудиозаписи из репозитория: Villager Sings MONTAGEM XONADA (зациклена), касса, ошибка, perfect-fart и восемь звуков комбо.

Сборка проверена компилятором в GitHub Actions. Интерактивная проверка в игровом клиенте и на серверах не проводилась.
