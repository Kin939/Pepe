## 1.0.4 — исправление вылета при первом стаке

Исправлен `IllegalStateException: Tried to access entity ID before ID assignment`
при пролёте жителя после 64 заработанных изумрудов. GUI-модель теперь получает
собственный локальный ID до первого обращения рендера. Модель по-прежнему не
добавляется в мир и не отправляется серверу.

Добавлены регрессионные проверки создания и повторного создания GUI-модели:
ID доступен сразу, сущность отсутствует в индексе мира.
Комбо за жителя, заработок, вращение, musor_drop и ускоренный дождь сохранены.

Удалите pepe-1.0.3.jar (и другие старые версии) перед установкой pepe-1.0.4.jar.
Сборка и автоматические тесты выполняются в CI. Проверка полного графического
рендера с вашей сборкой модов не проводилась.

Клиентский мод для Minecraft 26.3 / NeoForge 26.3.0.95, Java 25.

Установка: положить pepe-1.0.4.jar в папку mods **клиента**. На сервер устанавливать не нужно.

C — включение/выключение (можно переназначить). ПКМ по жителю — продажа за изумруды без отображения окна. Серверные лимиты сохраняются. Фильтр доступен через Mods → Pepe Auto Sell → Config и config/pepe-client.toml.

Комбо 1–8, сброс после 8, радужный финал и 500 экранных изумрудов. При отключении эффекты и музыка останавливаются.

Включены все запрошенные аудиозаписи из репозитория: Villager Sings MONTAGEM XONADA (зациклена), касса, ошибка, perfect-fart и восемь звуков комбо.

Сборка проверена компилятором в GitHub Actions. Интерактивная проверка в игровом клиенте и на серверах не проводилась.
