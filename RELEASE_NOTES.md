## 1.0.2 — массовая продажа и комбо

- Один ПКМ продаёт все разрешённые материалы до доступных лимитов жителя.
- Ванильный Shift-click результата вместо одиночного взятия и перекладывания каждого изумруда.
- Автодозаполнение входных слотов и перебор остальных разрешённых сделок без нового клика.
- Убраны фиксированные паузы по четыре тика на каждую операцию.
- Исправлено ожидание изменения stateId: успешная предсказанная ванильная операция не обязана вызывать ответный пакет слотов, из-за чего раньше учёт прибыли и комбо мог зависнуть.
- Прибыль считается по приросту изумрудов в инвентаре, а не по предмету на курсоре.
- Массовые продажи разбиваются на отдельные шаги комбо: 12 обменов → 1–8, затем 1–4.
- Звуки и анимация идут очередью независимо от скорости торговли, финал 8 остаётся видимым.

Удалите старый JAR перед установкой pepe-1.0.2.jar. Настройки фильтра сохраняются.
Сборка и автоматические тесты выполнены в CI; игровое тестирование на сервере не проводилось.

Клиентский мод для Minecraft 26.3 / NeoForge 26.3.0.95, Java 25.

Установка: положить pepe-1.0.2.jar в папку mods **клиента**. На сервер устанавливать не нужно.

C — включение/выключение (можно переназначить). ПКМ по жителю — продажа за изумруды без отображения окна. Серверные лимиты сохраняются. Фильтр доступен через Mods → Pepe Auto Sell → Config и config/pepe-client.toml.

Комбо 1–8, сброс после 8, радужный финал и 500 экранных изумрудов. При отключении эффекты и музыка останавливаются.

Включены все запрошенные аудиозаписи из репозитория: Villager Sings MONTAGEM XONADA (зациклена), касса, ошибка, perfect-fart и восемь звуков комбо.

Сборка проверена компилятором в GitHub Actions. Интерактивная проверка в игровом клиенте и на серверах не проводилась.
