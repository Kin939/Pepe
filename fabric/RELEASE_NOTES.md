## Pepe Fabric 1.0.8 — изумрудный экран и PEPE TV

Minecraft 26.3 / Fabric Loader 0.19.5 / Java 25.
Нужен отдельно установленный Fabric API 0.165.0+26.3.

- Изумрудная виньетка в режиме продажи, центр полностью прозрачный.
- Лёгкое плавное приближение/отдаление: FOV ±1.25%, цикл 5 секунд. Настройка FOV
  не перезаписывается; в меню и при выключенном режиме эффект отсутствует.
- Едва заметная зелёная заливка после продажи, красная при неудаче, затухание
  за 1 секунду. Около 6% максимальной непрозрачности, без накопления яркости.
- Убрана надпись AUTO SELL [C]. C можно переназначить в настройках управления.
- Оригинальная пиксельная CRT-панель PEPE TV слева внизу с пятью эмоциями жителя:
  нейтральной, успешной продажи, неудачи, достижения 64 изумрудов и максимального
  комбо. Праздничные эмоции приоритетнее обычных продаж.

Сохранены скрытая массовая продажа, фильтр, все звуки, комбо, дождь, заработок,
2D-пролёт и обводка с учётом инвентаря. Проверки сделок не вызывают новых эффектов.
Портрет — 2D PNG, без создания сущностей и без проблемного GUI-рендера жителя.

Фильтр: config/pepe-client.json, перечитывается при включении C.
Замените старый Fabric JAR файлом pepe-fabric-1.0.8.jar. NeoForge JAR сюда не ставить.

CI: компиляция, модульные тесты, запуск Fabric-клиента до главного меню.
Торговля на живых серверах и Windows/Overwolf не проверены.
