## Hype auto sell 1.1.0 — Emerald Arcade update (Fabric)

Minecraft 26.3 / Fabric Loader 0.19.5 / Java 25.
Нужен отдельно Fabric API 0.165.0+26.3.

PEPE → **Hype auto sell**, PEPE TV → **HYPE TV**.

Новый неоновый CRT HUD: анимированное появление, живой портрет с морганием,
пульсацией и реакцией на события, блики стекла, развёртка, LIVE LED, эквалайзер,
8 светодиодов комбо. Новый кошелёк с плавным счётчиком и прогрессом до стака.
Выезжающие карточки заработка, сегментированный HYPE COMBO и радужный HYPE OVERLOAD,
изумрудные искры и кольца, отдельный бирюзовый салют за стак, звёзды финала и
светящийся след 2D-жителя. Адаптивный масштаб, ограниченные очереди эффектов.

Торговля/фильтр/подсветка/комбо/музыка/дождь/виньетка/FOV сохранены.
Фоновые проверки ничего не продают и не вызывают эффектов заработка.

Внутренний ID `pepe` сохранён для обновления без потери конфига и назначенной клавиши.
Фильтр остаётся config/pepe-client.json. Удалите старый pepe-fabric JAR и установите
hype-auto-sell-fabric-1.1.0.jar. Старый и новый JAR одновременно не ставить.

CI: сборка, модульные тесты и запуск клиента до главного меню.
Проверка торговли на живом сервере/Windows не проводилась.
