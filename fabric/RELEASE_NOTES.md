Отдельный клиентский порт Pepe 1.0.7 на **Minecraft 26.3 / Fabric Loader 0.19.5 / Java 25**.

Нужен **Fabric API 0.165.0+26.3** в папке mods. NeoForge JAR сюда не устанавливать.

Сохранены скрытая массовая автопродажа, переназначаемая C, фильтр, все звуки,
комбо за успешный визит, радужный финал/дождь, заработок сессии и 2D-пролёт за
64 изумруда. Зелёная/красная обводка учитывает текущий инвентарь и известный запас
сделок; автоматические проверки читают сделки, но ничего не продают.

Фильтр: config/pepe-client.json (`allowlist`, `protectSpecialItems`, `items`).
Создаётся при первом запуске, перечитывается при включении C. Экран настроек
NeoForge в Fabric не переносился — редактируйте JSON при выключенном режиме.

Проверки CI: компиляция, модульные тесты, реальный запуск клиента под Xvfb до
главного меню с Loader 0.19.5. Торговля на живых серверах и Windows не проверена.
Перенос не является подтверждённым исправлением предыдущего нативного краша.
