# Hype auto sell — Fabric

Отдельный клиентский JAR для **Minecraft 26.3**, **Fabric Loader 0.19.5**, **Java 25**.
Нужен **Fabric API 0.165.0+26.3** (отдельный мод в `mods`). NeoForge не нужен.

## Установка

1. Создать экземпляр Minecraft 26.3 с Fabric Loader 0.19.5.
2. Положить `hype-auto-sell-fabric-1.1.0.jar` и Fabric API 0.165.0+26.3 в папку `mods` клиента.
3. Не ставить NeoForge JAR Pepe в этот экземпляр; не устанавливать на сервер.

C — включение режима, клавишу можно переназначить. ПКМ по жителю — скрытая
массовая продажа до исчерпания предметов/запаса/места, без обхода серверных лимитов.
Одиночная и многопользовательская игра поддерживаются обычными vanilla-пакетами.
Используйте только там, где разрешена автоматизация.

Перенесены комбо за успешный визит (1–8), радужный финал, ускоренный дождь,
счётчик заработка за сессию, вращающийся 2D-житель за каждые 64 заработанных
изумруда и все аудиозаписи. Выключение C очищает эффекты/очереди/счётчик/подсветку.

Зелёный контур — известна неисчерпанная сделка с изумрудами на выходе и хватает
разрешённых предметов для оплаты. Красный — запаса или предметов недостаточно.
Неизвестные сделки и жители без продаж за изумруды не подсвечиваются.
Изменения инвентаря проверяются каждый тик, серверный запас — скрытыми read-only
проверками видимых взрослых жителей в пределах 2.5 блока, при пустой второй руке
и без приседания. Не чаще 1 запроса/1.5 с; красные — раз в 10 с, остальные — 30 с.
Вдали запас остаётся последним известным. Свободное место под результат контур
не проверяет. Проверки не продают вещи и не начисляют комбо.

## Фильтр

Fabric использует **`config/pepe-client.json`**, а не NeoForge TOML. Файл создаётся
при первом запуске. Редактируйте при выключенном режиме, затем включите C —
настройки перечитаются. Отдельного экрана настроек Fabric пока нет.

```json
{
  "allowlist": false,
  "protectSpecialItems": true,
  "items": ["minecraft:diamond"]
}
```

`allowlist: false` запрещает перечисленные предметы; `true` разрешает только их.
Защита особых вещей сохраняется: имена, зачарования, повреждения и контейнеры.
Если защищённый предмет того же типа есть в доступных слотах, сделка пропускается.
Пустой список при `allowlist: false` разрешает все обычные входные предметы.
При неверном JSON сохраняется последний корректный фильтр и пишется ошибка в лог.

## Сборка

Из каталога `fabric`: `./gradlew build` (JDK 25). Независимая сборка на Loom 1.17.20
и Gradle 9.6.0, без зависимости от NeoForge. Торговый движок, политика доступности,
эффекты и ресурсы берутся из общих исходников родительского каталога.

CI выполняет модульные тесты, затем запуск клиента с Fabric Loader 0.19.5 под Xvfb
до главного меню. Это проверка загрузки/mixin, не полноценный тест торговли на
сервере и не проверка Windows/Overwolf. Нативный краш из-за окружения не обещаем
исправить переходом на другой загрузчик.

## Визуальные эффекты 1.1.0

Изумрудная виньетка, плавная пульсация FOV ±1.25% (5 секунд), прозрачная зелёная
вспышка при продаже / красная при неудаче (1 секунда, максимум ~6% непрозрачности).
Слева внизу — оригинальная 2D CRT-панель HYPE TV с эмоциями жителя: нейтральная,
успех, неудача, очередные 64 изумруда, максимальное комбо. Надпись AUTO SELL [C]
удалена; C переназначается в стандартных настройках управления, категория «Разное».
При выключении режима/выходе из мира эффекты очищаются. FOV в настройках не меняется.
